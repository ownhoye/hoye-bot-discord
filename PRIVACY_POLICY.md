# Privacy Policy

LoliCord is a client modification for Discord. It has no servers of its own and no LoliCord
account: plugins, themes, settings and keybinds run on your device and are never sent to us.

## What LoliCord downloads

LoliCord reads public files from its GitHub repository
(https://github.com/ownhoye/hoye-bot-discord):

- updates (releases),
- the LoliCord badge list (`badges.json`),
- the announcements shown in the official LoliCord channel (`announcements.json`).

As with any download, GitHub receives your IP address and user agent. See
[GitHub's Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

LoliCord also loads the public badge lists of Vencord, Equicord and Illegalcord, so those
services see the same technical information.

## Optional features using third-party services

Some features only contact another service if you enable or use them, for example:

- Cloud settings sync, with the Vencord or Equicord cloud you choose.
- AI and voice dictation plugins, with Groq, using your own API key.
- Translation, music (SoundCloud, Spotify) and file upload plugins, with their respective services.

Those services apply their own privacy policies.

## Discord

Since LoliCord modifies the official Discord client, all messaging, calls and server activity
still happen through Discord's own infrastructure and are governed by
[Discord's Privacy Policy](https://discord.com/privacy/).
